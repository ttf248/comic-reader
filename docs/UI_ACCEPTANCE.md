# UI / UX 验收清单（第二轮）

> 状态定义：
> - `OPEN` —— 尚未处理
> - `IN_PROGRESS` —— 正在实施
> - `BLOCKED` —— 有可证实的环境障碍（必须写明证据）
> - `VERIFIED` —— 已实现且通过实际检查（有代码变更 + 运行验证证据）

> 规则：**只有经过代码实现和运行验证的问题才能标记 VERIFIED。**

### C4. 剩余低优先级取舍（已知、刻意保留，不在本轮范围）

| 取舍 | 原因 |
|------|------|
| 视频封面在服务端抽帧完成前显示静态占位（图标 + 文案） | 抽帧要跑 ffmpeg，属后端耗时；前端只能如实占位。抽帧结果会缓存，第二次打开即是静态图 |
| 阅读器「适应」模式在竖屏看横图时四周留白较多 | 「适应」的定义就是整幅可见；要铺满需切「按宽」，这是既有语义 |
| 徽章类文字保留 11.5px、快捷键键帽 10.5px | 设计规范里 badge 档就是 11.5px；键帽显示的是单个符号而非中文正文 |
| 未读页不逐卡挂未读标记 | 整页都是未读，逐卡标记是纯重复；未读状态由页头统计与整页语义承担 |
| 首页的「随机一本 / 未读 / 最近 / 收藏」入口只在没有在读内容时出现 | 有在读内容时主操作位是「继续阅读」；没有在读内容时「随机一本」升为主操作。侧边栏始终提供全部入口 |
| 1920px 下正文宽度仍封顶 1440 | 超宽屏用居中阅读宽度而不是无限拉伸；超宽部分留给双列列表使用 |
