> 本文件记录 Local Gallery 前端在 2026-11 的一次产品级视觉与交互改造：
> 审计发现、设计规范、页面改动、两轮截图评审的结论与修正，以及验证命令与结果。
>
> 改造范围：**仅前端**。Go 后端、HTTP API、路由路径、Zustand store 结构、
> 键盘快捷键集合与持久化行为均保持不变。

## 2. 设计目标与原则

1. **内容优先** —— 图片 / 视频 / 封面是主角；界面退到背景。
2. **视觉克制** —— 去掉装饰性容器、边框、徽章、玻璃模糊；用留白与字重分组。
3. **信息清晰** —— 一屏一主角；每个元素只有一种含义；不重复表达。
4. **操作自然** —— 常用动作一步可达，次级动作收进菜单，但入口本身必须看得见。
5. **细节精致** —— 统一的字号、间距、圆角、阴影、动效节奏。

### 设计语言（自建，非照搬）

- **"纸面 + 画框"**：页面是纸面（`--bg`），内容是画框（无边框，仅靠间距与留白分组），
  只有浮层（菜单 / 弹窗 / 悬停卡）才使用阴影与描边。
- **单一强调色**：强调色只用于「主操作」「选中态」「进度」三处，不做装饰。
- **中文优先的排版**：不使用 `uppercase` / 大字距做章节标签；用"字号 + 字重 + 颜色"
  三段式（区块标题 15px/600、正文 14px、辅助信息 12.5px）。
- **信息密度分级**：`display`（页面主标题）→ `section`（区块标题）→ `body` → `meta`。
  最小字号 12.5px，杜绝 10px 中文。
- **强调色只做点缀**：选中态用 `accent-soft` 底 + `--fg` 文字，强调色只落在图标上，
  这样靛蓝 / 琥珀这类中明度强调色在浅底上也有稳定对比度。

## 3. 设计规范

### 3.1 排版

| 角色 | 字号 / 行高 | 字重 | 用途 |
|------|------------|------|------|
| `display` | 30px / 1.2 | 650 | 页面主标题（不再用 44px） |
| `section` | 15px / 1.4 | 600 | 区块标题（未读 / 时间线 / 全部图像） |
| `body` | 14px / 1.65 | 400 | 正文、说明文字 |
| `label` | 13px / 1.4 | 500 | 控件文字、卡片标题 |
| `meta` | 12.5px / 1.45 | 400 | 统计、路径、时间、快捷键提示 |
| `badge` | 11.5px / 1 | 500 | 仅用于**徽章**（角标），且只允许出现在短词或数字 |

> 关键约束：**任何承载中文正文的文本不得小于 12.5px**；`uppercase` +
> `tracking-[0.18em]` 不再用于中文标签。

### 3.2 间距 / 圆角 / 阴影

- 间距基线 4px；页面左右留白 `px-8`（移动端 `px-4`）；区块间距 40px。
- 圆角：封面 `12px`、控件 `8px`、菜单/弹窗 `12px`、徽章 `6px`。
- 阴影仅三级：`sm`（菜单）/ `md`（弹窗、悬停预览）/ `lg`（对话框遮罩层下）。
  卡片常态无阴影，hover 才轻微抬升。

### 3.3 色彩

沿用 `tokens.css` 的 CSS 变量 + Tailwind `theme.extend.colors`，**不硬编码色值**。
新增：

| token | 用途 |
|-------|------|
| `--bg-inset` | 卡片内的次级底色（比 `--bg-subtle` 更浅一档） |
| `--fg-disabled` | 禁用态文字 |

强调色 6 套（graphite / indigo / rose / forest / ochre / plum）继续通过
`[data-accent]` 覆盖，浅色深色各一套，保证对比度。

### 3.4 动效

- 时长：微交互 `120ms`、状态切换 `180ms`、浮层出现 `240ms`。
- 缓动统一 `--ease-out`。
- `prefers-reduced-motion: reduce` 时全部降为 0.01ms（保留状态变化本身）。

### 3.5 共享组件层

在 `global.css` 的 `@layer components` 里集中定义，组件代码不再各写各的 utility class：

| 类 | 用途 |
|----|------|
| `.page-shell` | 页面容器（最大宽度 1440 + 左右留白 32/16px） |
| `.page-title` | 页面主标题（30px / 650） |
| `.section-title` / `.section-meta` | 区块标题（15px/600）与辅助信息（12.5px） |
| `.btn` + `.btn-primary` / `.btn-outline` / `.btn-ghost` / `.btn-sm` | 三种语义、两种尺寸的按钮 |
| `.chip` | 筛选 chip（视图切换、标签切换），激活态 `accent-soft` 底 + `accent` 字 |
| `.badge` | 徽章（11.5px / 20px 高） |
| `.panel` | 真正需要"框"时（设置分组）才用的面板 |

## 4. 页面改动

### 4.1 全局布局

- **侧栏**：品牌区只保留图标 + `Local Gallery`；移除 10px 副标题与"导航"字样；
  导航项统一 13.5px / 36px 高，选中态 = `accent-soft` 底 + `--fg` 字 + 强调色图标；
  随机类操作与"设置"沉到底部一组，避免与主导航混排。
- **工具栏**：去掉与页面标题重复的 `Local Gallery / 图像库` 面包屑，
  改为只显示全局搜索 + 主题 / 帮助 / 更多；图标按钮统一 36px。
- **状态栏**：删除与筛选条重复的"视图 / 排序"，只保留库统计 / 扫描状态 /
  上次扫描 / 时间；字号提到 12px。
- **死代码清理**：`Breadcrumb.tsx` 与 `uiStore.breadcrumbs` 从未被渲染，
  一并删除（AGENTS.md「只保留最新实现」）。

### 4.2 首页

重排为 **单主角 + 三条内容带**：

```
┌ 页面头：图像库 · 104 本相册 / 28 个集合 · 上次更新      [重新扫描]
├ 继续阅读（横幅卡）：大封面 + 标题 + 进度条 + 「继续阅读」按钮 + 移除按钮
│   └ 其余在读相册降级为下方 6 张海报小卡
├ 次级入口行：随机一本 / 未读 N / 最近 / 收藏
├ 未读推荐（6 张，无容器盒子）
├ 时间线（年份海报）
└ 全部图像（筛选条 + 网格）
```

- 删除 4 张"动作卡"与"未读 / 继续阅读"外层边框盒。
- 继续阅读由**封面驱动的横幅**承担：左侧 140×176 封面，右侧标题 + 进度 +
  「继续阅读」主按钮；进度条贴在卡片底边，既是进度也给横幅一个视觉收尾。
- 区块标题改为 15px/600 中文章节名 + 右侧计数，不再用大写拉丁。

### 4.3 相册网格 / 卡片

- 移除 `进入` 药丸（整卡即链接，纯装饰）。
- 新增 `showUnreadBadge` 开关：未读页与首页未读区整页都是未读，
  卡片再逐张挂 `新` 角标只是噪音 → 整页关掉。
- 保留 `已读` / `重温` / 视频时长角标（承载真实状态），统一为 11.5px / 20px 高。
- 标题 13.5px/500，统计 12.5px `fg-muted`（原为 11px `fg-subtle`，对比度不足）。
- 统计行 `nowrap`：空间不够时让来源副标题截断，而不是把"19 个视 频"断成两行。
- 网格密度：封面 `4:5`，间距 `gap-x-5 gap-y-8`，1440px 下 6 列。

### 4.4 列表视图

- 缩略图从 80×100 压到 56×70，行高降到约 76px，一屏从 5 行变成 8 行。
- 行底加 `border-border-faint` 分隔线：整行铺满内容宽度时，没有分隔线的话
  标题与右侧数字之间是一大片空白，分隔线把它读成一张表。
- 小缩略图里的"正在加载…"提示改为紧凑模式隐藏（`CardCover compact`）。

### 4.5 阅读器

- 顶栏加**渐变遮罩 + 背景模糊**，明亮图片上的图标始终可读。
- 顶栏常驻「单张 / 连续 / 并排」分段控件与「适配」循环按钮
  （适应 → 按宽 → 按高 → 原始），核心操作不再全藏进"…"。
- 右侧悬浮控件移除与顶栏重复的"模式"分组；分组标签由 9px 大写拉丁改为 12px 中文。
- 「阅读设置」齿轮弹层在全尺寸可用（原来仅窄屏显示）。
- 控件高度统一 32px；页码计数 12.5px。
- 空状态重做，并修掉深色主题下"重试"按钮白底白字的问题（`text-accent-contrast`）。

### 4.6 搜索 / 筛选

- 筛选条统一为一行：**视图 chips（左）｜ 最少图数 · 共 N 项 · 排序 · 网格/列表（右）**，
  控件高度统一 30px、文字 13px。
- 没有视图 chips 的页面（未读 / 最近）把总数移到左侧，避免整条筛选条只剩右半边。

### 4.7 设置

- 页头改为共享 `page-title` + 13px 说明行。
- 分组标题改为 `section-title` 中文命名；分组面板圆角由 6px 提到 12px，
  与卡片、菜单的圆角语言一致；说明性文字统一到 12.5px。

## 7. 尚存问题

1. **阅读器顶栏在 1440px 下仍偏密**：模式组 + 适配 + 收藏 + 全屏 + 阅读设置 +
   更多共 6 组控件。更彻底的做法是改成一条底部居中的浮动工具条，但那会改变
   现有"右侧悬浮控件 + 顶栏"的布局契约，留待后续单独一轮。
2. **年份卡的大号年份数字在浅色封面（白底文档、白墙）上对比度一般**，
   目前只靠顶部渐变兜底，没有做局部文字描边。
3. **视频封面依赖浏览器抽帧**，抽帧完成前会显示转圈（列表视图里是紧凑态）。
   这是既有能力，本次只调整了提示的呈现方式，没有改变抽帧流程。
4. **未读页不再显示「新」角标**：如果用户依赖它区分"从未打开"与"打开过",
   需要到「收藏 / 最近」页查看。
5. **未做深色主题的全量对比度审计**：本次是人工抽查关键状态
   （正常 / 空 / 错误 / 悬停 / 选中），没有引入 WCAG AA 自动化检测。
6. **平板断点（768–1024px）未专门走查**：验收只覆盖了 1440px 桌面与 390px 手机。
7. **加载态仍是转圈 + 文案，没有骨架屏**：网格加载时没有内容占位，视觉上会"跳一下"。
8. **列表视图在超宽屏上仍是一列**：右侧数字列对齐，但标题与数字之间的空白
   没有进一步收敛（例如拆成两列网格），属于刻意保留的"扫读"取舍。
