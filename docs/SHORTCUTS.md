# SHORTCUTS · 快捷键全集

> 全局与阅读器快捷键来源：`frontend/src/utils/shortcuts.ts`；控件内的键盘操作由对应组件处理。
> 在应用里按 `?` 唤起可搜索帮助浮层，直接看实际生效的列表。

---

## 实现说明

- **输入框失效**：input / textarea / contentEditable 获得焦点时全局 hook 自动跳过（避免与中文输入法冲突）
- **按键规范化**：`normalizeKey()` 把 `ctrl` / `alt` / `shift` 拼成 `+` 分隔的字符串
- **跨键盘布局**：`?` / `+` / `=` 字面字符忽略 shift 前缀（AZERTY / QWERTZ 也能命中）
- **分组**：`group: 'global' | 'viewer' | 'album'`，HelpOverlay 按此分组渲染
- **修改流程**：改 `utils/shortcuts.ts` 的 `SHORTCUTS` 数组 → 同步改 handler 注册（`Toolbar` / `AppShell` / `Gallery`）→ HelpOverlay 自动同步

## 全局

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 重新扫描 |
| `Ctrl+H` | 回到主页 |
| `Ctrl+R` | 最近访问 |
| `Ctrl+D` | 我的收藏 |
| `Ctrl+,` | 设置 |
| `Ctrl+B` | 折叠 / 展开侧边栏 |
| `/` | 聚焦搜索框 |
| `R` | 随机一本（仅非画廊） |

## 列表排序

以下操作只在排序按钮及其展开选项内生效，不注册为全局快捷键。

| 按键 | 功能 |
|------|------|
| 排序按钮上的 `Enter` / `Space` | 展开或收起排序选项 |
| `Tab` / `Shift+Tab` | 按页面顺序切换焦点，离开排序区域时自动收起选项 |
| 选项上的 `Enter` / `Space` | 应用排序并将焦点返回排序按钮 |
| `Esc` | 取消展开并将焦点返回排序按钮，保留当前排序 |

点击区域外只关闭选项，焦点保留在点击的控件。

## 属性弹窗

| 按键 | 功能 |
|------|------|
| `Tab` / `Shift+Tab` | 在弹窗内的可用按钮间循环 |
| `Esc` | 关闭属性并将焦点返回打开它的相册卡片或图片 |

弹窗打开期间，背景页面的快捷键暂停响应；关闭按钮与背景遮罩也可关闭弹窗。

## 设置页目录输入

| 按键 | 功能 |
|------|------|
| 缓存或静态目录输入框中的 `Enter` | 保存该字段并离开输入框；正常失焦也会保存 |
| 缓存或静态目录输入框中的 `Esc` | 撤销该字段编辑草稿并离开输入框 |
| 媒体根输入框中的 `Esc` | 撤销整组根目录编辑草稿和新增空槽位，并离开输入框 |

媒体根沿用停止输入 450ms 后的整组自动保存。Esc 撤销仍在编辑的草稿，保留其他设置草稿，并恢复当前保存中的值或最新确认值。已经显示“保存中”的修改仍按顺序完成，不会撤销已开始的保存。输入法组合期间的 Enter / Esc 由输入法处理，不触发字段的确认或撤销。

输入法候选内容尚未确认时，媒体根整组与正在输入的文本、数字配置暂停自动保存。确认输入后，媒体根重新等待 450ms、其他自动保存配置重新等待 600ms，再提交最终值；其他字段仍可保存。正常失焦会确认当前组合内容，缓存和静态目录随后按原规则保存。

## 设置页目录选择

| 按键 | 功能 |
|------|------|
| 路径输入框中的 `Enter` | 前往输入的目录，成功读取后才可确认 |
| 文件夹按钮上的 `Enter` / `Space` | 浏览该子目录 |
| `Tab` / `Shift+Tab` | 在目录弹窗内循环焦点 |
| `Esc` | 取消选择，将焦点返回“选择本地目录”按钮 |

浏览与取消不保存路径；使用“使用此目录”确认完整路径。弹窗打开时背景页面快捷键暂停响应。

## 图片画廊

### 翻页 / 定位

| 快捷键 | 功能 |
|--------|------|
| `←` / `→` | 上一张 / 下一张（连续模式为滚一屏） |
| `PageUp` / `PageDown` | 同上 |
| `Home` / `End` | 第一张 / 最后一张（连续模式直接滚到首 / 尾） |
| `G` | 跳到指定页（输入页码 + 回车） |
| 拖底部进度条 | 跳到指定页（拖拽时浮出 5 张缩略图条） |
| 点击图片 | 左 1/3 上一张 / 右 1/3 下一张（中段无响应；缩放或拖拽时失效） |

### 跨卷

| 快捷键 | 功能 |
|--------|------|
| `N` | 下一本（按当前列表顺序：主页 / 收藏 / 标签 / 集合） |
| `P` | 上一本（按当前列表顺序） |

### 收藏

| 快捷键 | 功能 |
|--------|------|
| `S` | 收藏 / 取消收藏（与主页右键菜单一致） |

### 显示模式

| 快捷键 | 功能 |
|--------|------|
| `1` | 单张 |
| `2` | 连续滚动 |
| `3` | 双张并排（按 `L` 切换 LTR / RTL） |

### 图片适配

| 快捷键 | 功能 |
|--------|------|
| `F` | 适配循环：适应 → 按宽 → 按高 → 原始 |
| `L` | 翻页方向（仅双张并排：左→右 / 右→左） |

### 缩放 / 变换 / 信息

| 快捷键 | 功能 |
|--------|------|
| `+` / `=` | 放大 |
| `-` | 缩小 |
| `0` | 实际大小（100%） |
| `R` | 旋转 90°（**覆盖全局的随机一本**） |
| `I` | 切换图片信息面板（路径 / 尺寸 / 格式 / 大小 / mtime） |
| `F11` | 全屏切换 |
| `Space` | 幻灯片播放 / 暂停 |
| `Esc` | 退出全屏 → 关闭信息面板 → 关闭帮助 → 返回上一页 |

## 视频播放器

`/viewer?type=video&path=<album>&index=<n>` 进入。原生 `<video controls>` 自带控制条，下方是增强快捷键。

| 快捷键 | 功能 |
|--------|------|
| `Space` / `K` | 播放 / 暂停 |
| `←` / `→` | 倒退 / 快进 5 秒 |
| `↑` / `↓` | 音量 ±10% |
| `M` | 静音 / 取消静音 |
| `F11` | 全屏切换 |
| `Esc` | 返回上一页（与图片画廊一致） |

## 调试技巧

- `Ctrl+Shift+I` → DevTools → Console → `__KEY_HANDLERS__`（如果实现挂了）可看当前注册了哪些 handler
- 临时禁用所有快捷键：在 DevTools 里跑 `window.__disableShortcuts = true`
- 中文输入法冲突时，先按 `Esc` 退出输入法再触发快捷键
- `?` 不灵？大概率焦点在搜索框里——先 `Esc` 退出再按
