# SHORTCUTS · 快捷键全集

> 全局与阅读器快捷键来源：`frontend/src/utils/shortcuts.ts`；控件内的键盘操作由对应组件处理。
> 在应用里按 `?` 唤起可搜索帮助浮层，查看当前页面或媒体类型的操作。

---

## 实现说明

- **控件优先**：input / textarea / select / contentEditable（含子元素）中的按键由控件处理；按钮、链接及折叠摘要上的空格、回车不触发页面快捷键
- **事件优先级**：控件已调用 `preventDefault()` 或输入法仍在组合时，快捷键处理器跳过该事件；同一事件只由首个匹配处理器接管
- **修饰组合**：显式注册的 Ctrl / Meta 快捷键仍生效；视频控制和页码跳转不拦截带 Ctrl / Alt / Meta 的组合，`Ctrl+G` 不进入页码编辑
- **按键规范化**：`normalizeKey()` 把 `ctrl` / `alt` / `shift` 拼成 `+` 分隔的字符串
- **跨键盘布局**：`?` / `+` / `=` 字面字符忽略 shift 前缀（AZERTY / QWERTZ 也能命中）
- **分组**：`global` 为主页面，`photo` 为照片墙与大图预览，`reader` 为阅读器共用，`image` / `video` 为对应媒体操作。`HelpOverlay` 必须接收 `library` / `photo` / `image` / `video` 场景，先筛选分组再执行搜索
- **修改流程**：改 `utils/shortcuts.ts` 的 `SHORTCUTS` 数组 → 同步核对 handler 注册（`Toolbar` / `AppShell` / `Reader` / `PhotoViewer` / `VideoPlayer` / `PageSlider`）→ 更新测试和本文件

## 主页面

适用于主页、收藏、最近、设置和相册等带侧栏的页面；阅读器使用下方共用与媒体操作。

| 快捷键   | 功能                                                         |
| -------- | ------------------------------------------------------------ |
| `Ctrl+S` | 重新扫描；已有活动任务或进度连接中断、结果待确认时不重复启动 |
| `Ctrl+H` | 回到照片库 / 回到漫画库（随工作台模式）                       |
| `Ctrl+R` | 最近浏览 / 最近阅读（随工作台模式）                           |
| `Ctrl+D` | 收藏照片 / 收藏漫画（随工作台模式）                           |
| `Ctrl+,` | 设置                                                         |
| `Ctrl+B` | 折叠 / 展开侧边栏                                            |
| `/`      | 聚焦搜索框                                                   |
| `R`      | 随机翻翻（照片工作台）/ 随机一卷（漫画工作台）               |
| `U`      | 未读相册页（只属于漫画工作台，照片模式下不跳转）             |
| `?`      | 显示快捷键帮助                                               |
| `Esc`    | 关闭当前浮层                                                 |

工作台模式进 URL 路径，因此这些跳转的目标随模式变化：`Ctrl+H` 到 `/photo` 或 `/comic`，`Ctrl+R` 到 `/photo/recents` 或 `/comic/recents`，`Ctrl+D` 到 `/photo/favorites` 或 `/comic/favorites`，`U` 固定到 `/comic/unread`（照片侧没有未读这个页面）。

`R` 在主页面随机打开相册，在图片阅读器旋转图片；`U` 在主页面打开未读列表，在图片和视频阅读器设置封面。
主页面两条的措辞随工作台模式变化：「随机翻翻 / 随机一卷」。未读只属于漫画工作台，照片模式下按 `U` 不跳转，帮助浮层里也不列出这条快捷键。

工作台模式（照片 / 漫画）的切换**刻意不给快捷键**：常见候选（`Ctrl+Shift+M`、`Ctrl+Shift+P`、`Ctrl+Alt+M`）都被主流浏览器的开发者工具或打印占用，而模式切换在顶栏与设置页都是一步可达的控件，不需要再占一个全局键。

## 足迹页

适用于 `/photo/travels`。页面里有两处可键盘操作：时间轴与行程目录。正文右栏的地图是只读的，不进 Tab 序列。

### 时间轴

时间轴是一排按真实时间比例铺开的月格，两端各有一个抓手。抓手是滑块（`role="slider"`），用方向键移动。

| 快捷键                | 功能                                     |
| --------------------- | ---------------------------------------- |
| `Tab`                 | 在跨度控件、两个抓手与格子上方的小钉之间移动 |
| `←` `→`（焦点在抓手上） | 把这一端移动一个月                       |
| `Shift` + `←` `→`     | 把这一端移动一年                         |
| `Home` / `End`        | 把这一端移到时间轴的起点 / 终点          |
| `Enter` / `Space`（焦点在小钉上） | 选中这一段行程                   |
| `Esc`（焦点在抓手上） | 清空区间（也可以用「清除区间」按钮）     |

跨度控件是一组单选（`1年 / 3年 / 5年 / 10年 / 全部`），左右方向键切换，缺省是最近五年。换跨度会清掉刷手圈出的区间 —— 换跨度就是换了一个范围。

悬停某一格或某颗小钉，标题行右侧的读数给出确切的值（那个月的张数，或那一段的日期、地点链与张数）；不悬停时读数报的是当前范围。

区间状态写在地址的 `from`/`to` 上，跨度写在 `span` 上，浏览器前进后退可以回到上一段区间。

### 地图

地图在正文右栏里，宽 320–440 像素（随视口缩放）：它只回答「去过哪些地方」，不提供平移缩放，也不单独用键盘访问 —— 那个尺寸下区划只有几个像素宽，逐个 Tab 穿过几十个省份没有意义。要去某个地方，用地图上方窄栏里的「地方」清单。

### 行程目录

行程目录按时间排成一段段，一行一段；点开才就地展开照片带与整段的照片。

| 快捷键                | 功能                                     |
| --------------------- | ---------------------------------------- |
| `Tab`                 | 在段头、照片带与「看这 N 张」之间移动   |
| `Enter` / `Space`     | 选中这一段（再按一次取消）               |
| `Enter`（照片带上）   | 打开这一段的照片                         |
| `Enter`（「看这 N 张」） | 就地展开这一段的全部照片               |

照片带上的每一张都是一个按钮，`Enter` 打开大图；大图里的翻页与加载更多沿用照片墙的约定。地点链里的地名也是按钮，`Enter` 进入这个地方的详情页。

地点详情页的每一条到访记录都是一个按钮，`Tab` 到达、`Enter` 就地展开那几天拍的照片；再按一次收起。

## 快捷键帮助

| 按键                           | 功能                                       |
| ------------------------------ | ------------------------------------------ |
| `Tab` / `Shift+Tab`            | 在关闭、搜索和当前可用的清除按钮间循环焦点 |
| `Esc`                          | 关闭帮助，焦点返回打开它的按钮或控件       |
| 关闭按钮上的 `Enter` / `Space` | 关闭帮助并恢复来源焦点                     |

打开帮助时聚焦搜索，输入内容即时过滤列表；清除搜索后焦点回到搜索框，重新打开时清空过滤条件。帮助使用模态弹窗，背景页面不可交互，浮层内按键不会触发翻页、视频播放或全局导航。点击遮罩也可关闭帮助；阅读器中第一次 Esc 只关闭帮助，随后可再按 Esc 返回相册。

阅读器与相册页的"返回"在应用内还有上一页时才回退；直接打开链接（刷新、复制链接到新标签页）时改回应用内的相册页/主页，不会退回浏览器的空白页。

主页面只展示主页面操作；图片和视频分别展示阅读器共用及对应媒体操作。同样搜索 `Space`，图片显示幻灯片，视频显示播放 / 暂停；主页面没有该页面快捷键。切换媒体类型会保留搜索词并刷新匹配结果。

照片墙是主页面的一种形态：帮助里在全局操作之外多一组「照片墙」操作，即大图预览的翻页、缩放、全屏、信息面板与关闭。照片墙的全局操作措辞随工作台模式变化（照片工作台是「最近浏览」「收藏照片」，漫画工作台是「最近阅读」「收藏漫画」）。

## 弹出菜单

适用于阅读器“更多”、右键菜单和工具栏主题菜单。打开时聚焦第一个可用项；全部禁用时聚焦菜单本身。

| 按键                | 功能                                   |
| ------------------- | -------------------------------------- |
| `↑` / `↓`           | 在可用项间循环，跳过禁用项             |
| `Home` / `End`      | 第一个 / 最后一个可用项                |
| `Enter` / `Space`   | 执行当前项                             |
| `Esc`               | 只关闭当前菜单，焦点返回来源控件       |
| `Tab` / `Shift+Tab` | 按页面顺序移动焦点，离开菜单时自动关闭 |

菜单内按键不会触发背景翻页、换片或视频控制；Ctrl / Alt / Meta 组合保留浏览器行为，不移动菜单焦点。关闭时若焦点已经移到外部控件，就保持该焦点；没有可用项的菜单仍可用 Esc 关闭。

主题菜单只包含浅色 / 深色 / 系统三项。方向键只移动焦点，`Enter` / `Space` 确认当前选择并保持菜单打开，便于连续调整；当前主题显示选中状态。

## 列表排序

以下操作只在排序按钮及其展开选项内生效，不注册为全局快捷键。

| 按键 | 功能 |
|------|------|
| 排序按钮上的 `Enter` / `Space` | 展开或收起排序选项 |
| `Tab` / `Shift+Tab` | 按页面顺序切换焦点，离开排序区域时自动收起选项 |
| 选项上的 `Enter` / `Space` | 应用排序并将焦点返回排序按钮 |
| `Esc` | 取消展开并将焦点返回排序按钮，保留当前排序 |

点击区域外只关闭选项，焦点保留在点击的控件。

## 设置页目录输入

| 按键 | 功能 |
|------|------|
| 缓存或静态目录输入框中的 `Enter` | 保存该字段并离开输入框；无新草稿时重试保留的失败输入；正常失焦只保存新草稿 |
| 缓存或静态目录输入框中的 `Esc` | 撤销该字段编辑草稿与失败输入，并离开输入框 |
| 媒体根输入框中的 `Esc` | 撤销整组根目录草稿、失败输入和新增空槽位，并离开输入框 |

媒体根沿用停止输入 450ms 后的整组自动保存；没有新草稿时，Enter 可重试整组失败输入。Esc 撤销当前字段的草稿和保留的失败输入，保留其他设置草稿，并恢复当前保存中的值或最新确认值。已经显示“保存中”的修改仍按顺序完成，不会撤销已开始的保存；根目录写入结果不明时，可用“重新读取配置”确认服务端状态。输入法组合期间的 Enter / Esc 由输入法处理，不触发字段的确认或撤销。

输入法候选内容尚未确认时，媒体根整组与正在输入的文本、数字配置暂停自动保存。确认输入后，媒体根重新等待 450ms、其他自动保存配置重新等待 600ms，再提交最终值；其他字段仍可保存。正常失焦会确认当前组合内容，缓存和静态目录随后按原规则保存。

## 设置页目录选择

| 按键 | 功能 |
|------|------|
| 路径输入框中的 `Enter` | 前往输入的目录，成功读取后才可确认 |
| 文件夹按钮上的 `Enter` / `Space` | 浏览该子目录 |
| `Tab` / `Shift+Tab` | 在目录弹窗内循环焦点 |
| `Esc` | 取消选择，将焦点返回“选择本地目录”按钮 |

浏览与取消不保存路径；使用“使用此目录”确认完整路径。弹窗打开时背景页面快捷键暂停响应。

## 阅读器共用

下列操作适用于图片和视频；跨相册依赖进入阅读器时保存的列表上下文。
切到下一本时仍在阅读器内继续读（集合没有阅读器入口，会回到它的首页）；
目标相册没有当前这类媒体时自动跳过。设置里的「阅读到末尾自动切换下一本」
会让读完最后一张时自动切到下一本，「切换时显示通知」控制切换提示。

| 快捷键         | 功能                                     |
| -------------- | ---------------------------------------- |
| `?` / `Ctrl+/` | 显示快捷键帮助                           |
| `N` / `P`      | 按当前列表顺序切到下一本 / 上一本（留在阅读器里继续读） |
| `S`            | 收藏 / 取消收藏当前相册                  |
| `U`            | 将当前图片或视频设为相册封面             |
| `Shift+U`      | 清除相册的自定义封面                     |
| `F11`          | 全屏切换                                 |
| `Esc`          | 关闭帮助或信息面板；媒体就绪时返回上一页 |

## 漫画阅读器

漫画相册直接进入阅读器（`/read/<相册 id>`）。照片相册走照片墙，不使用这里的操作。

### 翻页 / 定位

| 快捷键 | 功能 |
|--------|------|
| `←` / `→` | 上一页 / 下一页（连续模式为滚一屏） |
| `PageUp` / `PageDown` | 同上 |
| `Home` / `End` | 第一页 / 最后一页（连续模式直接滚到首 / 尾） |
| `G` | 跳到指定页（输入页数 + 回车） |
| 拖底部进度条 | 跳到指定页（拖拽时浮出 5 张缩略图条） |
| 点击图片 | 左 1/3 上一页 / 右 1/3 下一页（中段无响应；缩放或拖拽时失效） |

### 显示模式

| 快捷键 | 功能 |
|--------|------|
| `1` | 单页 |
| `2` | 连续滚动 |
| `3` | 双页并排（按 `L` 切换 LTR / RTL） |

### 图片适配

| 快捷键 | 功能 |
|--------|------|
| `F` | 适配循环：适应 → 按宽 → 按高 → 原始 |
| `L` | 翻页方向（仅双页并排：左→右 / 右→左） |

### 缩放 / 变换 / 信息

| 快捷键    | 功能                                                  |
| --------- | ----------------------------------------------------- |
| `+` / `=` | 放大                                                  |
| `-`       | 缩小                                                  |
| `0`       | 实际大小（100%）                                      |
| `R`       | 旋转 90°                                              |
| `I`       | 切换图片信息面板（路径 / 尺寸 / 格式 / 大小 / mtime） |
| `T`       | 打开目录：整本缩略图网格，点一下跳到那一页           |
| `Space`   | 幻灯片播放 / 暂停                                     |

## 视频播放器

`/read/<相册 id>?type=video&index=<n>` 进入，`index` 是视频列表内从 0 开始的序号。原生 `<video controls>` 自带控制条，下方是增强快捷键。

| 快捷键                | 功能                  |
| --------------------- | --------------------- |
| `Space` / `K`         | 播放 / 暂停           |
| `←` / `→`             | 倒退 / 快进 5 秒      |
| `PageUp` / `PageDown` | 上一个 / 下一个视频   |
| `Home` / `End`        | 第一个 / 最后一个视频 |
| `↑` / `↓`             | 音量 ±10%             |
| `M`                   | 静音 / 取消静音       |

视频模式不响应图片的显示模式、适配、方向、缩放、旋转、信息与幻灯片快捷键，空格仅控制视频播放；保存的图片连续或双页模式不影响视频换片、首尾定位及单个视频计数。图片幻灯片计时在视频模式暂停，回到图片模式后继续按原状态运行。媒体仍在加载或加载失败时，Esc 不触发页面返回，可使用顶部返回按钮。

## 照片墙

照片相册直接进入照片墙（`/albums/<相册 id>`）：平铺浏览所有图片与视频，点开是沉浸式大图预览。
照片墙没有页码、阅读进度与双页模式，这些是漫画阅读器专属的。

### 照片墙

| 操作 | 功能 |
|------|------|
| 点击图片 | 打开大图预览 |
| 点击视频 | 在大图预览里播放 |
| 顶部「密度」 | 切换行高（密集 / 标准 / 宽松） |
| 「更多」菜单 / 卡片右键 | 复制相册链接、设为封面、收藏、在系统文件管理器中打开 |

内容属性按目录设置且互斥：照片目录里的相册进照片墙，漫画目录里的相册进阅读器。相册页没有「归类」动作——属性只由所属媒体根决定，单本相册不能改。

### 大图预览

| 快捷键 / 操作 | 功能 |
|----------------|------|
| `←` / `→` | 上一张 / 下一张 |
| `Home` / `End` | 第一张 / 最后一张 |
| `+` / `-` | 放大 / 缩小 |
| `0` | 恢复适应屏幕 |
| 滚轮 | 放大 / 缩小 |
| 拖拽 | 放大后拖动画面 |
| 双击 | 在适应屏幕与 200% 之间切换 |
| `F` | 全屏切换 |
| `I` | 切换图片信息面板 |
| `P` | 精选 / 取消精选这张照片（照片级，与收藏相册不同） |
| `C` | 放进并排对比 / 与待对比的那张并排打开 |
| `Esc` | 关闭预览，回到照片墙原位置 |
| 触摸左右滑动 | 上一张 / 下一张 |

并排对比开在大图预览之上时，预览不接按键：`Esc` 归对比，翻页也不在看不见的
预览里发生。关掉对比之后预览仍在原处。

### 照片精选与并排对比

照片墙的精选角标在悬停时露出，点一下就把这张加入精选；多选模式（页头的方框
按钮）里可以一次勾选多张，底部的操作条随之出现。

| 操作 | 功能 |
|------|------|
| 悬停照片左上角的圆圈 | 加入 / 移出精选 |
| 页头的方框按钮 | 进入 / 退出多选（再按一次退出） |
| 多选时点击照片 | 勾选 / 取消勾选 |
| 多选操作条上的「加入精选」/「移出精选」 | 批量改精选状态 |
| 多选操作条上的「并排对比」 | 打开两张照片的并排对比（需正好勾两张图片） |

## 使用提示

- 输入框或可编辑区域保留文本操作；先离开输入区域，再使用页面快捷键。
- 按钮获得焦点后可用空格或回车激活，包括阅读器返回、菜单和视频重试按钮。
- 主页面工具栏和阅读器“更多”菜单也提供帮助入口，可直接用鼠标打开。
